---
name: phase-gate
description: Run the end-of-phase gate: tests, review, report, daily note, wait for the user go.
---

1. Run the phase checks and show real output.
2. Have a fresh subagent review the phase diff.
3. Report what passed and what could not be tested.
4. Write vault/daily/<date>.md (done, checked, open, next); commit and push the vault.
5. Update the Project JARVIS doc if a decision changed; say what changed.
6. Stop and wait for the user go before the next phase.
